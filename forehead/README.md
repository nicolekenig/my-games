# Forehead

A classic guessing game where you hold your phone to your forehead and friends give you clues to guess the celebrity or character displayed. Features a 60-second timer that runs continuously and tracks your correct answers and passes.

## How to Play

1. Press **▶ Start** to begin the timer
2. Hold the phone to your forehead (or place it face-up on a table)
3. Friends give you clues about the character displayed
4. When you guess correctly, press **✅ Correct** (resets timer to 1:00)
5. If stuck, press **⏭ Pass** to skip (no timer reset)
6. Timer runs forever — when it hits 0:00, it resets to 1:00 automatically

## Controls

| Button | Action |
|---|---|
| ▶ Start / ⏸ Pause | Start or pause the timer |
| ⏱ Reset Timer | Manually reset timer to 1:00 |
| 🎭 New Character | Change to a different character |
| ⏭ Pass | Skip character (counts as pass, no timer reset) |
| ✅ Correct | Mark as correct (resets timer to 1:00, new character) |

## Features

- **80+ characters** across categories:
    - Movie stars (Tom Cruise, Gal Gadot, etc.)
    - Fictional characters (Harry Potter, Batman, etc.)
    - Singers (Taylor Swift, Beyoncé, etc.)
    - Israeli celebrities (Bar Refaeli, Noa Kirel, etc.)
    - Sports stars & icons

- **Continuous timer** — runs forever until manually paused
- **Smart character pool** — no repeats until all characters are used
- **Score tracking** — correct answers and passes never reset
- **Color-coded timer** — changes color based on time remaining:
    - White: 31-60 seconds
    - Orange: 11-30 seconds
    - Red: 0-10 seconds

## Notes

- This is a **single-player/local multiplayer** game (no server needed)
- Works offline — all characters are built into the game
- Mobile-optimized with large, touch-friendly buttons
- Timer persists even when changing characters manually
- Perfect for parties, road trips, or family game night!

## Tips

- **For clue-givers:** Describe without using the exact name
- **Example:** For "Harry Potter" → "Boy wizard with a scar"
- **Use gestures** when playing in person for extra fun
- **Set a round limit** — first to 10 correct answers wins!

## Game Strategy

- **Press ✅ Correct quickly** to maximize time for the next character
- **Don't be afraid to Pass** — some characters are harder than others
- **Use the ⏱ Reset Timer button** if you want to pause between rounds without stopping the timer completely
